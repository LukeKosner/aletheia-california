## Broke or learned

- The FPPC portal's public search/download flow uses browser search tickets. Normal browser search succeeded; the PDF button produced no captured download. Bulk automated intake remains incomplete. The implementation accepts normal downloaded files instead of recreating the portal's access-control mechanism.
- No TokenRouter key was present in the task environment. The sponsor's official setup guide verifies `.com` API hosting; similarly named `.io` services must not receive this project's keys. No live provider request was sent.
- Plain PDF text loses checkbox selection information. The extraction prompt requires null uncertain ranges, and the human checklist explicitly checks visual ranges and ownership context. Text support is not an accuracy/completeness metric.
- Amendments can contain only changed schedules. Preserve originals and all amendments and review them together; do not sum all staged rows or infer that a partial amendment replaces the entire original.
