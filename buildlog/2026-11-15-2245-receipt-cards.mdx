Integer cents recompute categories from unique receipt edges; missing evidence, duplicate edges, unaggregated individuals, and excessive categories are rejected.

## Broke or learned

- P10 is the dependent base branch. This PR does not merge or deploy it. P12/P15 contracts are documented in the card integration boundary, but their unmerged packages are not imported into this independently reviewable branch.
- Live cards remain blocked on read-only card/claim receipts, trusted verifier output, reviewer identity/role enforcement, version-bound human approval, persistent short aliases, and publication/correction kill-state reads. Current schema/tools cannot safely persist the full flow within this folder scope. The queue is explicitly a recorded preview, not a working approval service.
- Next Cache Components rejects an explicit route runtime setting and requires Suspense around cookie-dependent pages; both were corrected and the final production build passed. Runtime QA also identified the session expiry clock being evaluated during prefetch; the session helper now explicitly waits for a request with `connection()` before reading the clock. A clean-cache production rebuild resolved an unrelated restricted CSS subprocess cache failure.
- The image renderer cannot resolve CSS variables/oklch, so its palette reads existing theme tokens and converts them rather than introducing hard-coded colors. No dependency, migration, database write or public feature was added.
