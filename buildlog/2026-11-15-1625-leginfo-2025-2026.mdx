## Broke or learned

- BILL_SUMMARY_VOTE_TBL disagrees with the website on 2,096 roll calls, mostly the ABSTAIN count for Senate committees (it reads 0). On SB 329's Assembly floor vote of 2026-08-25 its ayes are wrong too: 77–0–2 vs 76–0–3 on the site. Counts are built from member rows; the summary table is only a cross-check.
- The `vote` table has no roll-call id. In 31 cases a bill has two roll calls with the same date, location and motion, which the database can't tell apart. Needs a schema change (outside this task's folders).
- `bill_author_role` has no principal-coauthor value; PRINCIPAL_COAUTHOR maps to `coauthor`.
- 286 bills are authored only by a committee and have no `bill_author` rows (committees aren't legislator entities).
- leginfo.legislature.ca.gov returns a Cloudflare JavaScript page to scripts; website counts were read in a browser and saved as a fixture.
- Committee matching needed nicknames (Tom/Thomas, Ben/Benjamin, ...) and compound surnames (Ortega/Ortega-Toro). Name-only rows include possible different people, e.g. "Robert Garcia for Lt. Governor 2026".
