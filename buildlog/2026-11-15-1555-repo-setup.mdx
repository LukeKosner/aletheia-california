## Broke or learned

- AI Elements targets Radix-style shadcn components; the preset uses Base UI. Patched type errors in `prompt-input`, `inline-citation` and `plan`: hover-card delays move from Root to Trigger (`delay`, `closeDelay`), dropdown items use `onClick` instead of `onSelect`, and `PlanTrigger` passes props to `CollapsibleTrigger` with `render={<Button />}`.
- `shimmer` used `#0000` in a gradient; replaced with `transparent` so the color check passes.
- React Compiler lint rules (`set-state-in-effect`, `static-components`) are warnings, not errors, for vendored `components/ui` and `components/ai-elements`, so upstream updates apply cleanly.
- `drizzle-kit push` with `strict: true` needs a TTY; in a non-interactive shell it errors. Checked the plan had no drops, then used `--force` on the empty database.
- `next typegen` runs before `tsc` so `LayoutProps` exists in CI.
