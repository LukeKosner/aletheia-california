## Shipped

- `scripts/provision_dev_db.py`, run once against the dev database with the owner's approval: creates the five agent views (migration 0001), the auth tables (migration 0002) and eight least-privilege login roles with the grants already specified in `packages/tools/sql/grants.sql`, `agents/README.md`, the auth README and the feedback integration notes. It writes the role connection strings to the gitignored `apps/web/.env.local` and prints no secret.
- `agents/sync-harnesses.ts` creates or updates five HarnessRouter harnesses (scope check, measure, bill, footprint, interests) and records them in `agents/harnessrouter.json`. Standing instructions are stored in each harness, every built-in tool of the base is disabled, and the four investigation harnesses reach only the Aletheia MCP server through a stored secret reference.
- Scope check moved from TokenRouter Chat Completions to its own harness (`agents/instructions/scope.md`, `HR_SCOPE_HARNESS_ID`). The investigation route no longer needs `TOKENROUTER_API_KEY`; HarnessRouter bills models through the TokenRouter key stored in its dashboard.
- `agents/models.json`: scope check and writer run `claude-sonnet-5.5` on the `dsh` base, the pairing HarnessRouter's own guide gives for strict-JSON replies. Verifier is planned as `gpt-5.6-sol` (a different family) and is not wired yet.
- Private deployment at `aletheia.lukekosner.com` (Vercel project root `apps/web`, DNS-only CNAME in Cloudflare). `PUBLIC_SITE` stays off; `.vercelignore` keeps raw data, Python and worktrees out of the upload.

- A harness on the `claude-code` base with all nine tools disabled did not receive its stored `system_prompt`: asked directly, the model said it had no such instruction and answered the question instead of classifying it. The same prompt on `dsh` was followed. Cause not established.
- `dsh` reports `enforcement: instruction` for five file tools (read, write, edit, glob, grep) and `hard` for the rest, including bash and web fetch. `agents/README.md` asked for hard enforcement of every tool; this is weaker for sandbox file access and should be reviewed before anything public.
- `claude-haiku-4.5` returned a provider 400 through the TokenRouter integration, and `claude-haiku-5.5` is not offered by it.
- The free HarnessRouter plan runs two tasks at a time (HTTP 429 `one_at_a_time` beyond that).
- Neon's owner role is not a superuser, so `alter role ... nosuperuser noreplication nobypassrls` in `grants.sql` fails there. The script strips those three words; new roles already have those defaults.
